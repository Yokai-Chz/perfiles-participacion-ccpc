# Guía SDD: constitución

Entrada: principios a proponer o revisar.

Lee `AGENTS.md`, `MEMORY.md`, `docs/constitution.md` si existe y la estructura del proyecto. Propón principios breves y verificables para stack, relación entre spec y código, separación de responsabilidades, pruebas, protección de datos e idioma. Muestra el texto y solicita aprobación antes de modificar la constitución. Si se aprueba un cambio duradero, actualiza `MEMORY.md`.
