# Guía SDD: tareas

Entrada: nombre `NNN-nombre`.

Lee la spec aprobada y `plan.md`. Solicita autorización antes de crear `tasks.md`. Divide el plan en tareas pequeñas, ordenadas por dependencia. Cada tarea lleva casilla, RF cubiertos y `Hecho cuando:` con una comprobación verificable. Asigna las validaciones del plan a tareas concretas. Si salen más de diez, propón dividir la spec. Presenta plan y tareas para aprobación explícita antes de implementar.
